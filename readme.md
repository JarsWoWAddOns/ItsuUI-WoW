# Itsu:UI (retail)

This is the retail version of Itsu:UI, for World of Warcraft 12.1. The WoW: Forever version lives in [ItsuUI-WoW4EVA](https://github.com/JarsWoWAddOns/ItsuUI-WoW4EVA).

Action bars, unit frames, cast bars, bags, NPC chat, class resource, XP bar and a controller mode in one addon. `/jf` for options.
